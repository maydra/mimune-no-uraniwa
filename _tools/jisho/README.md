# 原理用語辞典（jisho/）

ポケ辞書（pokejisho.com）のように、日本語・韓国語・英語のどれで引いても3つが並んで出る辞典。2026-10-26 に作った（ユーザー「こういう感じの、日韓英の原理用語辞書を作りたい」）。

- ページ: `jisho/index.html`（`build_jisho.py` が作る。手で直さない）
- 元のデータ: `terms.json`（語を直す・足すときはこれを直して `python -I -X utf8 _tools/jisho/build_jisho.py`）
- 語の行は全部ページに書き出してあり、検索は JS で行を絞り込んで並べ替えるだけ（JS が無くても全部読める）

## terms.json の決まり

- **訳語は本に実際に出ている形だけ**。日本語は『原理講論』の日本語訳、韓国語は原典『원리강론』、英語は *Exposition of the Divine Principle*（1996年）。`ref` の段落に3つともそのまま出ていること（`work/validate.py` で確かめられる）
- `ref` は対訳（taiyaku/genri_kouron）の「節の鍵:段落（0始まり）」。ページの「原理講論で読む」は `#節の鍵-段落+1` で対訳のその段落へ飛ぶ
- `id` は付け直さない（`#t123` で語を指すリンクに使う）。用語は下の候補の番号、人名・地名は 2001 から
- `n` は並べる順（原典で漢字が添えてある回数。人名・地名は英語に出る段落の数）
- 韓国語の下のカナは `_tools/seika/hangul_kana.py` で作る（数字は 3대 → 삼대 と読んでから）
- 検索の鍵（各行の `data-k`）: 日本語・よみ・韓国語・漢字・英語と、韓国語のカナ。カナはパッチムの小さいカナ（ㇰ ㇺ ㇽ ㇷ゚）を普通のカナに直した形と、ㄱ・ㅂ のパッチムを ッ にした形（ポックィソムニ）の2つ（2026-10-26、ユーザー「チョンドリョンって打っても出ない」）。小さいカナは NFKC でも直らないので、`norm()`（Python と JS の両方）で直す

## 最初の版の作り方（work/）

1. `extract_pairs.py`: 韓国語の原典で「한글(漢字)」と漢字が添えてある語を全部集める（1,898組）。漢字を新字体に直し（`shinjitai.py`）、日本語訳の同じ段落に出るかを見る（7割はそのまま出る。残りは「埃及→エジプト」のように日本語訳が別の語を使う）
2. 候補を一つずつ見て、原理講論を読む人・訳す人が引く語を残した（`keep.txt`、492語。ありふれた言葉は外した）
3. `packets.py` が、候補ごとに3言語の段落の抜き出しと英語の候補（`en_align.py`。語の出る段落と出ない段落で英語の言い回しの出方を比べる）を付けて4つの束に分け、`TASK.md` の手順で1語ずつ本文を読んで ja・yomi・ko・en を決めた。人名・地名は `names.txt` の英語から `cooc.py` で日本語・韓国語の形を探した
4. `validate.py` で、3つの語が ref の段落にそのまま出ているかを全件確かめ、`merge.py` でまとめた。よみは Sudachi の読みと比べ、違うものを本文のルビ・読み慣わしで見直した

`work/` の台本は、対訳のデータ（`taiyaku/genri_kouron/data`）から `extract_pairs.py` を回すと作り直せる（出てくる rows.json などは大きいので commit しない）。`out1〜4.jsonl`・`names.jsonl` は4つの束と人名・地名で決めた結果（外した語の理由・迷った語の flag もここにある）、`fixes.json` はまとめたあとの手直し（重なりの整理・侍義時代と知情意の追加など）。`TASK.md` の中のフォルダは作ったときの一時フォルダ。

最初の版は 590 語（原理 236・信仰・聖書 126・歴史・思想 73・人名 92・地名・民族 63）。
