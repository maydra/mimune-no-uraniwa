『原理講論 要約訓読チャート（12時間用）』（世界平和統一堂）の図を、原理講論のページ（dp/）に出すために SVG で描き直す。
明るい配色・暗い配色の両方で読め、どのフォントでも崩れないことを優先する。見本は `svg/z095.svg`（四位基台）と `svg/z180.svg`（人の姿・半分ずつ色の付いた円・色の面の上の矢じり）。

- viewBox は元の画像の大きさ `0 0 W H`（前編は 1303×689 が多い）。**座標は元の画像のピクセルに合わせる**（重ねて見比べるため）。width・height は書かない
- 元の画像は `E:\mimune-no-uraniwa\dpcharts-work\charts\zen\imageNNN.png`（著作物なのでリポジトリには入れない）

## 後編の図（id が k で始まる）
- 元の画像は `E:\mimune-no-uraniwa\dpcharts-work\charts\kou\imageNNN.png` で、多くは **822×435**（前編の 1303×689 の約 0.63 倍）。viewBox は元の画像の大きさにする
- 線の太さと字の大きさの目安も 0.63 倍にする: ふつうの線 2.2、四位基台などの太い線 5.7、灰色の曲がった矢印 4.4、点線 `9 6`、本文の字 21〜28、題 28〜30。人の姿・十字架の型の縁（3）も 2 くらいにする

## ルート要素（このまま写す）
```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1303 689" class="dpc-svg" role="img" font-family="'BIZ UDPGothic','Hiragino Sans','Hiragino Kaku Gothic ProN','Noto Sans JP','Yu Gothic',Meiryo,sans-serif" font-weight="700" fill="currentColor">
  <title>図の題（題が無い図は中身を短く）</title>
```
- `<style>`・`<script>`・`<image>`・`<foreignObject>`・`<use>`・外のファイルへの参照は使わない（build_charts.py が止める）。class は `paper` だけ
- **id は全部「<id>-」で始める**（z095-g など）。1ページに何十枚も並ぶので、id が重なると矢じりが別の図のものに入れ替わる
- 元の画像の**外枠の四角は描かない**（ページの枠が代わりをする）。それ以外は全部描く

表に無い色は元の画像に近い色を使い、報告する。元の灰色の矢印はもっと濃い（約 `#687C83`）が、暗い配色で見えるように `#8C949A` にそろえる。

暗い配色でも読めるように、色は次の3つに分けて書く。
1. **地の上の線と字は currentColor。** 明るい配色で黒、暗い配色で明るい灰になる。ルートに `fill="currentColor"` があるので、字は何も書かなければこれになる。線は `stroke="currentColor"`
2. **白い丸・白い箱は `fill="#fff" class="paper"`。** 暗い配色では暗い紙の色に変わる。中の字と縁は 1 と同じ（currentColor）
3. **色の付いた面（表の色）の上に乗る字・線・矢じりは `#111`。** 暗い配色でも黒のまま（面の色は変わらないので）。こげ茶など濃い面の上の字は `#fff`

矢じりの `<marker>` は、**定義した所の色で塗られる**（使う線の色ではない）。fill を固定の色にして、地の上用（`currentColor`）・面の上用（`#111`）・灰色用（`#8C949A`）を分けて定義する。

地と色の面をまたぐ線（大きな楕円の外から中へ入る線、矢印の面を横切る点線など）は、面の中の区間を `#111`、外を `currentColor` に分けて描く。片方の色だけだと、暗い配色でどちらかの区間が消える。

## そろえ方
同じ物（同じ人物の楕円・十字架・人の姿など）は**色と形**をそろえる。**大きさと位置は元の図に合わせる**。そろえるために元より大きく・小さくしない（メシヤ論の z450 で、ほかの図に合わせて楕円を 385→249 に細くし、元の見た目が変わった。2026-10-31 に元の寸法に戻した）。

## 字
- 太字（ルートで 700）。大きさは元の画像の字の高さに合わせる（1303 幅の図で、本文の字は 34〜44、題は 44〜48 くらい）
- 和文は1字が約 1em の幅として見積もる（フォントで少し違う）。箱や楕円の中の字は、左右に 0.3em 以上の余白を残す
- 真ん中に置く字は `text-anchor="middle" dominant-baseline="central"`
- **下線つきの題**や、線・箱とぴったり合わせたい字は `textLength` と `lengthAdjust="spacing"` で幅を決める（どのフォントでも下線と同じ長さになる）。textLength は「字数×字の大きさ」より小さくしない（字が重なる）
- 縦書きは1字ずつ縦に並べる。`<tspan>` を改行して並べると、改行が空白として入り、真ん中寄せが約 9px ずれる。tspan は1行に続けて書くか、1字ずつ別の `<text>` にする。「ー」は「｜」、括弧は「︵ ︶」など縦の形にする
- 小さい読み（ルビ）は小さい字で上に置く
- 元が細字の所（聖句の本文・括弧書き・添え字）は `font-weight="400"` にしてよい。元が横に詰めた字は `lengthAdjust="spacingAndGlyphs"` で幅を合わせてよい
- ローマ数字は「Ⅰ Ⅱ Ⅲ」の字（U+2160〜）で書く。ラテン文字の I は使わない
- 「霊人体＜性相／形状」のように2行へ分かれる「＜」「｛」や、「●」「・」の点は、字ではなく線・円で描く。字で置くと、コピーや読み上げで「霊人体く性相」のようになるうえ、フォントで位置がずれる
- **字は元の画像のとおりに写す**（漢字・送り仮名・記号・聖句の出典も）。読み取れない字を推測で埋めず、報告する
- 「蕩減」を「蕩滅」と写し違えやすい（減と滅が似ている。2026-10-31 までに5枚）。書いたら「蕩滅」で探して無いことを確かめる
- ただし元の図の**明らかな誤記**（聖句の章節の誤り・書名の字の誤りなど）は、報告して、ユーザーの了解を得てから直す。直した所には SVG のコメントで元の表記と理由を残す（z509「ルカ 24:43」→ 23:43、z451「烈王下」→ 列王下。2026-10-31、ユーザー「誤表記は直そう」）

十字架（幅 100×高さ 180 の型。メシヤ・復活論・後編に何度も出る）。**元の十字架の幅と高さに合わせて `scale(sx,sy)` で置く**（縦横で倍率が違ってよい。元の十字架は図ごとに幅÷高さが 0.47〜0.61 と違う）:
```xml
<g transform="translate(X,Y) scale(SX,SY)" fill="#7A5230" stroke="#111" stroke-width="W" stroke-linejoin="round">
  <path d="M40,0 H60 V42 H100 V60 H60 V180 H40 V60 H0 V42 H40 Z"/>
</g>
```
縁の太さ W は 3÷((SX+SY)÷2)（拡大しても縁がほかの線と同じ太さに見えるように。`vector-effect` は画面の画素で太さが決まり、ページで縮めたときに太く見えるので使わない）。
（初めは幅 110×高さ 160 の型を縦横同じ倍率で置いていたが、元より幅が 40〜60px 広くなった。2026-10-31 に作り直し、描いた図の十字架も元の寸法に合わせ直した）

塗りの変化（linearGradient）は、元の図で塗りがはっきり変わっている所（心霊・知能の発達の三角、霊界の層の帯）だけに使う。id は「<id>-」で始める。

## 見比べ方
```
python -I -X utf8 _tools/dpcharts/render.py _tools/dpcharts/svg/z095.svg E:/mimune-no-uraniwa/dpcharts-work/cmp/z095.png --ref E:/mimune-no-uraniwa/dpcharts-work/charts/zen/image160.png
```
- 上が描いた SVG、下が重ねた図（赤=元の画像だけ、水色=SVG だけ、黒=両方）。外枠の赤は消さなくてよい
- 赤と水色が大きく離れている所（線・円・箱・字の位置）を直す。フォントの違いによる字の形の細かいずれは気にしない
- `--dark` を付けると暗い配色で描く。字が地や面に溶けていないかを確かめる
- 何人かで同時に描くときは、測るための一時ファイルを各自のフォルダに置く（同じ名前のファイルを上書きし合った。2026-10-30）
