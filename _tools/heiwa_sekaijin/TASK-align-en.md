# 韓英の対応付け（『平和を愛する世界人として』）

韓日の対応付け（TASK-align.md）が済んだので、同じことを韓国語と英語でやる。韓国語の原文と英語版を、節ごとに
「どの韓国語のかたまりが、どの英語の文にあたるか」で対応させる。目標は**韓国語も英語も1つ残らず、正しい相手と組になること**。

## 材料（読むだけ。書き換えない）
- `work/sections-en/NN.txt` … 節ごとの一覧。`K1:` が韓国語の番号付きのかたまり（原文の段落）、`E1 [p1]:` が英語の文（`[p1]` は英語版の段落）
- 英語版は韓国語から訳したものだが、日本語版より**自由に組み替えている**。段落の切り方・順番が違う、2〜3文を1文にまとめる、
  省く、英語圏の読者向けに説明を足す、節の題が別物（1章8節は「日本人はどうぞ日本に帰りなさい」が「Ardent Student」）など
- 手本: 韓日の対応表 `work/align/NN.json`（形は同じ。`ja` が `en` になる）

## 書くもの: `work/align-en/NN.json`

```json
{"no": 7, "groups": [
  {"ko": [1], "en": [1, 2]},
  {"ko": [2, 3], "en": [3, 4, 5], "note": "E4 が K2 の終わりと K3 の頭にまたがる"},
  {"ko": [4], "en": [6, {"ko": "그때 형사들은 나를 거꾸로 매달고 물을 부었습니다."}, 7], "note": "英語版は拷問の場面を省いている"},
  {"ko": [5], "en": [{"ko": "（K5 の全文）"}], "note": "K5 は英語にまったく無い"}
]}
```

決まりは韓日（TASK-align.md）と同じ:
- `groups` は韓国語の順。組はできるだけ小さく（ふつうは韓国語1かたまり＝1組。英語の1つの文が2つの韓国語のかたまりにまたがるときだけまとめる）
- `en` には、その韓国語にあたる英語の文の番号を、**韓国語の流れに沿う順**で並べる。英語版が順番を入れ替えている所は、韓国語の順に並べ直してよい
- **英語に無い韓国語**は、`en` の中のあるべき位置に `{"ko": "省かれている韓国語"}` として入れる。丸ごと無ければ全文、一部なら区切りのよい所まで。**字は原文からそのまま写す**（`work/sections/NN.json` から機械で切り出すとよい。使い捨てのスクリプトは scratchpad `C:\Users\PC_User\AppData\Local\Temp\claude\E--auto-videos-creation\a85a5e0d-a243-4061-9624-972a79241584\scratchpad\` に置く）。あとでここを英語に AI 訳して埋める
  - 言い回し・意訳・まとめ方の違いは「省略」に数えない。**中身（出来事・人・数・発言・理由・場面）が英語から消えているもの**だけを `{"ko"}` にする。事実を足す従属節も拾う
- 英語にだけあって韓国語に無い文（英語圏向けの説明など）は、いちばん近い組の `en` に入れて `note` に書く
- 英語の中身が韓国語と食い違う所（数・場所・年・人数など）は、`note` に「食い違い: 」で始めて書く
- `note` は日本語で短く（作業者向け。画面には出ない）

## 特別な節
- **00（序文）**: 英語版の序文は元のファイルに無い。韓国語のかたまりごとに `{"ko": [n], "en": [{"ko": "（そのかたまりの全文）"}]}` の組にする（序文はまるごと AI 訳になる）
- **53（6章7節）**: 韓国語も英語も元のファイルに無い。`{"no": 53, "groups": []}` でよい

## 確かめる
リポジトリの根（`E:\mimune-no-uraniwa\mimune-no-uraniwa`）で

    python -I _tools/heiwa_sekaijin/check_align.py NN --lang en

を回し、「誤り」が無くなって `OK` が出るまで直す。「知らせ」は誤りではないが、目を通して、おかしければ直す。
