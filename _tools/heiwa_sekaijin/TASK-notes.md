# 読む人向けの注を書き足す（『平和を愛する世界人として』韓日対訳）

韓日の対応表（`work/align/NN.json`）はできている。各組の `note` は作業者向けのメモで、画面には出ない。
この作業では、画面に出す注を組に書き足す。対訳を読む人が「並びは合っているのに中身が違う」所で戸惑わないようにするため。

## 材料
- `work/align/NN.json` … 対応表。各組の `note` に「食い違い: …」や、省略・書き換えのメモがある
- `work/sections/NN.txt` … 韓国語の原文（K）と日本語版（J）の全文
- `python -I _tools/heiwa_sekaijin/preview.py NN` … 組ごとに韓国語と日本語を並べた一覧を `work/preview/NN.txt` に書く（見るのに便利）

## 書き足すもの（組に足す。ほかのキーは変えない）

```json
{"ko": [19], "ja": [20, 21, 22], "note": "（作業者向けのメモ。そのまま残す）",
 "diff": ["原文では大村収容所に入れられた（日本語版は「広島と山口の刑務所」）",
          "原文では一週間以内に送還するのが当時の日本の法（日本語版は「約九カ月間の刑務所生活」）"],
 "ja_only": [21],
 "ja_only_ko": "그러나 그 후에도 몇 차례 선교사 파견을 시도했지만 모두 성공하지 못했습니다."}
```

### `diff`（日本語の欄の下に「※」で出る）
日本語版が**中身を書き換えている所**を、読む人向けに1つ1文で書く。
- 対象: 数・年・日付・期間・場所・人数・年齢・人名などが違う所／意味が逆・別になっている所／文の途中の語句が落ちて意味が変わる所（「日本の警察」→「警察」など）／発言の中身が違う所
- 形: **「原文では〜（日本語版は「〜」）」**。原文の中身は自分で日本語に訳して書く。日本語版の言い方は「」で引く。日本語版に無いだけなら「（日本語版にはない）」
  - 例「原文では飢える人は数千万人（日本語版は「数億人」）」「原文では「日本の警察」（日本語版は「警察」とだけ）」「原文では七、八歳のころ（日本語版は「十七歳」）」
- 年が1つだけ若い所（数え年を満年齢に直したらしい所）は、「原文では十六歳（日本語版は「十五歳」。数え年を満年齢に直したか）」
- 書かないもの: 言い回し・意訳の違い／訳者が足した括弧の説明（「(郡の首長)」など）／ウォンを円に換えただけの所／日本語に無い文や語句で、`{"ko"}` の AI 訳で補ってあるもの（AI 訳の行に出ているので、注で繰り返さない。2026-10-30 に「（日本語版にはない）」の注を7つ外した）
- 番号（J12・K3・組）や「韓国語の」「J20 は」のような作業の言葉は入れない。読む人には通じない
- 根拠は `note` の「食い違い:」だが、`note` だけに頼らず、組の韓国語と日本語を読んで確かめる。`note` が「省略」と書いていても、文の途中の語句なら `diff` にする

### `ja_only` と `ja_only_ko`（日本語版にしか無い文）
日本語版にあって**原文の韓国語に無い文**（訳者が足した文）を、その組の `ja` にある文の番号で `ja_only` に並べる。
- 文の一部に括弧の説明が足されているだけなら入れない。**文の中身がまるごと原文に無い**ものだけ
- `ja_only_ko` には、その文（複数なら全部）を韓国語に訳して書く。韓国語の欄に「일본어판에만 있는 문장 · 일본어에서 AI 번역」の札付きで出る。原文と同じく「-습니다」体で、人名・用語は原文の書き方に合わせる（崔奉春＝최봉춘、神様＝하나님）
- 日本語版のみの文が無い組には何も足さない

## 確かめる

    python -I _tools/heiwa_sekaijin/check_align.py NN

が OK になること（`diff` に番号が入っていない、`ja_only` がその組の文の番号、`ja_only_ko` が韓国語、を確かめる）。
渡された節のファイルだけを書く。JSON を書き直すときは、`groups` の `ko`・`ja`・`note` を変えない。
