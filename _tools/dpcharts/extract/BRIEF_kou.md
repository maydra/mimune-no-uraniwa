# 後編の図を SVG で描き直す担当への手順

み旨の裏庭（ユーザーが運営する み言のアーカイブサイト）の原理講論のページに出す図を、SVG で描き直す。元の図は『原理講論 要約訓読チャート（12時間用）』の画像で、ユーザーの依頼で描き直している。ほかにも何人かが別の図を同時に描いている。

## まず読むもの
- `E:\mimune-no-uraniwa\mimune-no-uraniwa\_tools\dpcharts\STYLE.md`（決まり。全部読む。とくに「後編の図」「そろえ方」・色の表・挿絵・十字架・人の姿の型）
- 見本 `E:\mimune-no-uraniwa\mimune-no-uraniwa\_tools\dpcharts\svg\z095.svg` と `z180.svg`（前編の見本。読むだけ。後編は線と字を 0.63 倍にする）
- 字だけの図（聖句や箇条を並べた図）があれば、手本 `svg\z225.svg` も読む

## 元の画像
`E:\mimune-no-uraniwa\dpcharts-work\charts\kou\<画像>.png`。多くは 822×435 で viewBox="0 0 822 435"。違う大きさの図は頼まれた文に書いてある。必ず画像の大きさを確かめて viewBox にする。

## よく出る物の色（表の色を使う）
- イエス・アベル・ヤコブ・モーセ・ノア・民主主義など天の側の人物と楕円: 黄 `#F8F28F`
- カイン・エサウ・イスラエル民族・ユダヤ民族・共産など: 朱 `#F86D42`
- 堕落した人・アダム（堕落後）・サタン側の国や思想: 茶 `#CF921C`
- サタン・天使長・サタン側: こげ茶 `#50403D`（字は白）
- 心・霊人体・宗教: 桃 `#F98AEE`／体・肉身・科学: 緑 `#A0F08A`
- 水色の箱: `#CDF8F7`、灰桃の箱: `#DCC4C4`、薄い桃: `#FCE5E3`
- 丸で囲んだ「神」「サ」「人」などは円と字に分けて描く。× は線2本、○ は円
同じ人物は担当の中で色と形をそろえる。**大きさと位置は元の図に合わせる**（そろえるために動かさない）
**頼まれた文や上の表の色と、元の図の色が違うときは、元の図の色にする**（元で白い楕円は `fill="#fff" class="paper"`、中の字は currentColor）。そろえるために元の色を変えない

## 1枚ずつの手順
1. Read で元の画像を見る
2. Write で `E:\mimune-no-uraniwa\mimune-no-uraniwa\_tools\dpcharts\svg\<id>.svg` を書く
3. 見比べ図を作り、Read で見る（上が SVG、下が重ねた図。赤=元だけ、水色=SVG だけ）:
   `python -I -X utf8 E:/mimune-no-uraniwa/mimune-no-uraniwa/_tools/dpcharts/render.py E:/mimune-no-uraniwa/mimune-no-uraniwa/_tools/dpcharts/svg/<id>.svg E:/mimune-no-uraniwa/dpcharts-work/cmp/<id>.png --ref E:/mimune-no-uraniwa/dpcharts-work/charts/kou/<画像>.png`
4. 大きくずれている所（線・円・箱・字の位置、抜けた要素）を Edit で直し、もう一度だけ見比べる。見比べは1枚につき2回まで。フォントの違いによる細かいずれは追わない
5. 担当の中で色の付いた面のある図を1〜2枚選び、`--dark` を付けて暗い配色でも描いて見る（字が地や面に溶けていないか）

## 守ること
- 書いてよいのは担当の SVG、`E:\mimune-no-uraniwa\dpcharts-work\cmp\` の見比べ図、自分の作業フォルダ `E:\mimune-no-uraniwa\dpcharts-work\tmp\<組の名前>\` だけ。STYLE.md・見本・dp/ のページ・ほかの人の SVG には触らない。git の操作（add・commit など）はしない
- **「蕩減」の「減」を「滅」と写し違えやすい**（前編・後編で5枚あった）。元の図はどれも「蕩減」。書き終えたら SVG の中を「蕩滅」で探して、無いことを確かめる
- 字は元の画像のとおりに写す（漢字・送り仮名・記号・聖句の出典も）。読み取れない字は推測で埋めず、最後に報告する。元の図の明らかな誤記（聖句の章節・書名の字など）に気づいたら、直さずに報告する
- 地図・写真のような絵（世界地図・朝鮮半島など）は、平たい図形で形を写す（細かい海岸線は省いてよい）。実在の人物の写真は描かない
- Bash で python を動かすときは `-I -X utf8` を付ける
