# 原理原本 日韓対訳（taiyaku/genri_genbon）

『原理原本』（文鮮明先生が 1951〜52年に書いた原稿）の韓国語の原文と、日本語訳を段落ごとに並べる。
日本語訳は AI による訳で、公式の訳ではない（公式の日本語訳は無いと認識している）。

## 元にしたもの

- 原文: Daum カフェ「천일국 경전방」の掲示板 WD3Y「原理原本 (김현주)」 https://cafe.daum.net/ckatkfkdrhdqn/WD3Y
  - 原稿1ページ＝1記事。1〜447ページ（398ページの記事は無い）。巻は 1巻 1〜176、2巻 177〜328、3巻 329〜447 ページ
  - 1記事の中は「掲示板の日本語訳の段落 → 漢字まじりの韓国語（原文）の段落」の組
- 日本語訳: 原文から AI（Claude）が訳した。掲示板の日本語訳（김현주 さん）は答え合わせにだけ使った（誤訳が多い。他性的→惰性的、同性體→同姓体、引力→人力 など）
- **リポジトリに入れるのは原文と、ここで作った訳だけ。** 掲示板の日本語訳と、落とした記事（raw/）は入れない

## これから直すとき

`units.json` の `ja`・`note` などを直に直して、作り直す。

```
python -X utf8 _tools/genbon/build_genbon.py
```

`work/` の台本は、最初に作ったときの記録。落とした記事などの元データが無いと動かない。

## units.json（805段落）

| 鍵 | 中身 |
|---|---|
| `id` | 段落の通し番号 |
| `vol` | 巻 |
| `parts` | `[[原稿のページ, 韓国語], …]`。原稿のページの切れ目で途中になった文は次のページの頭とつないで1段落にしたので、2つ以上のページにまたがる段落がある |
| `ja` | 日本語訳。ページが替わる所に `〔123〕` の印（`parts` のページと数・順がそろう） |
| `heading` | 原稿の見出し。ここで節を分ける（38節） |
| `sub` | 節に分けるほどでない小見出し |
| `note` | 訳の断り書き。段落の下に「※」で出す |

## 訳の決まり

- 하나님 は「神様」。敬語は残す
- 訳は最大限、原文に近く。文の数と順は原文どおり。補うときは（　）
- 原文の漢字語はその字のまま（新字体に）。ハングルで書いた語は原理講論の日本語に合わせる（예수→イエス、탕감→蕩減）
- 原文の字が別の語の意味に取れる所は、その意味で訳し、断り書きに「原文「持点」は支点の意として訳した」と書く。**「書き誤り」「誤り」とは書かない**（原文の字にも意味があるかもしれない）
- ただし言い換えた語も日本語としてなじみの薄い語なら、原文の字のまま（複雑多段・結判・有物相通）
- 語をそろえる: 百姓→民、祖上→先祖。原文の「支邦」は「支那（中国）」
- 断り書きに段落の通し番号を書かない（ビューアの段落番号は節ごとなので、たどれない）

## 作り方（最初の一回）

1. `work/crawl.py` … 掲示板の記事を全部落とす（raw/）
2. `work/parse.py` … 行を ja（日本語）・mix（漢字まじりの韓国語）・ko（ハングルだけ）・other に分ける → pages.jsonl
3. 行の分け方を手で直す → pages2.jsonl。31ページより後のハングルだけの行と、図・表の漢字だけの行も原文（最初は落としていた）
4. `work/units2.py` … ページの切れ目で途中になった文をつなぐ → 805段落
5. 9つの束に分けて訳した（決まりは `work/TASK.md`、確かめは `work/validate_wb.py`）。`work/units.py` は3.の直しの前の段落分けで、`compose.py` が前の訳を当て直すのに使う
6. `work/compose.py` … 訳をまとめ、手で直した所（行を戻して変わった18段落の訳、語のそろえ、原文の字に戻した所、断り書きの言い方）を当てる → units.json（`board` は除いて入れる）
7. `build_genbon.py` … taiyaku/genri_genbon/ を作る

## ビューア

- 原理講論の三か国語対訳のビューア（`taiyaku/genri_kouron/index.html`）を写し、`build_genbon.py` の `patch_viewer` で日韓2列用に書き換える。書き換えが当たらなければ止まるので、原理講論のビューアを変えたら作り直して確かめる
- 設定は `wb.` の鍵で覚える（原理講論は `dp.`）
- 節の題の上に機械翻訳の「お断り」の枠。右上の × で消え、その端末では消えたまま（`wb.noticeHidden`）
- 本文をまとめてコピーしても、※ の断り書きと〔123〕のページの印は入らない（`.note`・`.pg` を選べなくし、copy イベントでも抜く）
