# 日本語版で省かれた所の AI 訳（『平和経』）

日本語版の『平和経』は、韓国語の原文を所々省いている（小見出しを丸ごと落とした講演もある）。対訳では、その省かれた韓国語を日本語に訳して、
公式の訳のあいだの元の位置に入れる。画面では「AI訳（韓国語から）・公式訳ではありません」の札を付けて、公式の訳と見分けられるようにする。
やり方は『平和を愛する世界人として』（`_tools/heiwa_sekaijin/TASK-translate.md`）と同じ。

## 材料（読むだけ）
- `work/trans/todo/HHNN.txt` … 訳す所の一覧。1か所ごとに
  - `## 0411:3fa2c9d1e0` … 印（訳を書くときの鍵）
  - 訳す韓国語／その組の韓国語の全文（前後の文脈）／直前と直後の日本語（公式の訳）／対応付けのメモ
- `work/sections/HHNN.txt` … その講演の韓国語と公式の日本語の全文。用語の訳し方はここで確かめる

## 書くもの: `work/trans/ja/<担当の名前>.json`

```json
{"0411:123d81c574": "1. 神様の理想家庭",
 "0411:9ac3711c28": "2. 血統の重要性"}
```

- 印は todo の `## ` の行のものをそのまま使う。担当した印を1つ残らず訳す
- `<担当の名前>` は、ほかの担当とぶつからない名前にする（担当した講演の番号を入れる。`0405-0412.json` など）

## 訳し方
- **公式の訳の文体に合わせる。** です・ます調。話し手の一人称は「私」。年・数は公式の訳と同じく漢数字（一九七二年、三千万）。会話・引用は「」
- **小見出しは、公式の訳の小見出しの形に合わせる。** 韓国語に番号（「1.」）があれば残す。体言止めのまま、文にしない
- **用語は、同じ講演（なければ前後の講演）の公式の訳と同じ書き方にする**（하나님＝神様、참사랑＝真の愛、참부모＝真の父母、참가정＝真の家庭、섭리＝摂理、탕감＝蕩減、축복＝祝福、천주＝天宙、심정＝心情、혈통＝血統、복귀＝復帰、천일국＝天一国、평화대사＝平和大使）。公式の訳に出てこない語は、統一教会の日本語の文書でふつうに使う書き方にする
- **原文に忠実に。** 省かれた所を補うのが目的なので、要約しない・和らげない・足さない
- **前後とつながる日本語にする。** 韓国語が文の途中から始まる・途中で終わるときは、直前・直後の公式の訳と自然につながる形にする。ただし公式の訳に書いてある内容を繰り返さない
- 公式の訳の文は直さない。訳すのは渡された韓国語だけ

## 確かめる
リポジトリの根（`E:\mimune-no-uraniwa\mimune-no-uraniwa`）で

    python -I -X utf8 _tools/heiwakyou_taiyaku/frags.py check

を回すと、全体でそろった数と、訳の無い印・ハングルが残っている訳が出る。自分の担当の印が「訳が無い」に出なくなればよい（ほかの担当の分は出ていてかまわない）。
