# 日本語訳で省かれた所の AI 訳（『平和を愛する世界人として』）

日本語の公式の訳は、韓国語の原文を所々省いている。対訳では、その省かれた韓国語を日本語に訳して、
公式の訳のあいだの元の位置に入れる。画面では「AI訳（韓国語から）・公式訳ではありません」の札を付けて、
公式の訳と見分けられるようにする。

## 材料（読むだけ）
- `work/trans/todo/NN.txt` … 訳す所の一覧。1か所ごとに
  - `## 07:3fa2c9d1e0` … 印（訳を書くときの鍵）
  - 訳す韓国語／その組の韓国語の全文（前後の文脈）／直前と直後の日本語（公式の訳）／対応付けのメモ
- `work/sections/NN.txt` … その節の韓国語と公式の日本語の全文。人名・地名・用語の訳し方はここで確かめる

## 書くもの: `work/trans/ja/<担当の名前>.json`

```json
{"28:3fa2c9d1e0": "そして韓国へ送り返されました。私は彼をもう一度日本へ送りましたが、今度も日本の警察に捕まり、戻されてきました。",
 "28:9b1e04c2aa": "…"}
```

- 印は todo の `## ` の行のものをそのまま使う。担当した印を1つ残らず訳す

## 訳し方
- **公式の訳の文体に合わせる。** です・ます調、語り手（文鮮明先生）の一人称は「私」。年・数は公式の訳と同じく漢数字（一九五五年、百五十万圜）。会話は「」
- **人名・地名・用語は、同じ節（なければ前後の節）の公式の訳と同じ書き方にする**（최봉춘＝崔奉春、갑사＝甲寺、하나님＝神様、참사랑＝真の愛、참부모＝真の父母、통일교회＝統一教会、식구＝食口、정성＝精誠、탕감＝蕩減、섭리＝摂理）。公式の訳に出てこない語は、統一教会の日本語の文書でふつうに使う書き方にする
- **原文に忠実に。** 省かれた所を補うのが目的なので、要約しない・和らげない・足さない。拷問や暴力の場面もそのまま訳す
- **前後とつながる日本語にする。** 韓国語が文の途中から始まる・途中で終わるときは、直前・直後の公式の訳と自然につながる形にする（たとえば直前の公式の訳が「日本に到着するとすぐに逮捕されてしまいました。」で、訳す韓国語が「한국으로 되돌아왔습니다. …」なら「そして韓国へ送り返されました。…」）。ただし公式の訳に書いてある内容を繰り返さない
- 公式の訳の文は直さない。訳すのは渡された韓国語だけ

## 確かめる
リポジトリの根（`E:\mimune-no-uraniwa\mimune-no-uraniwa`）で

    python -I _tools/heiwa_sekaijin/frags.py check

を回すと、全体でそろった数と、訳の無い印・ハングルが残っている訳が出る。自分の担当の印が「訳が無い」に出なくなればよい（ほかの担当の分は出ていてかまわない）。
