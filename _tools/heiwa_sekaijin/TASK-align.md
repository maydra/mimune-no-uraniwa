# 韓日の対応付け（『平和を愛する世界人として』）

韓国語の原文と日本語訳を、節ごとに「どの韓国語のかたまりが、どの日本語の文にあたるか」で対応させる。
できた対応表から、サイトで韓・日（のちに英）を横に並べる対訳を作る。目標は**韓国語も日本語も1つ残らず、正しい相手と組になること**。

## 材料（読むだけ。書き換えない）
- `work/sections/NN.txt` … 節ごとの一覧。`K1:` が韓国語の番号付きのかたまり（原文の段落）、`J1 [p1]:` が日本語の文（`[p1]` はサイトの段落）
- 日本語は韓国語から訳したものだが、**省いた所が多い**（とくに日本や刑罰・拷問・家族の事情などを、まるごと、または一部だけ省いている）。言い換え・まとめ・順番の入れ替えもある

## 書くもの: `work/align/NN.json`

```json
{"no": 7, "groups": [
  {"ko": [1], "ja": [1, 2]},
  {"ko": [2, 3], "ja": [3, 4, 5], "note": "J4 が K2 の終わりと K3 の頭にまたがる"},
  {"ko": [4], "ja": [6, {"ko": "그때 형사들은 나를 거꾸로 매달고 물을 부었습니다."}, 7], "note": "拷問の場面を日本語は省いている"},
  {"ko": [5], "ja": [{"ko": "（K5 の全文）"}], "note": "K5 は日本語にまったく無い"}
]}
```

- `groups` は韓国語の順に並べる。どの組も `ko`（韓国語の番号、連続した昇順）と `ja`（日本語）を持つ
- **組はできるだけ小さく。** ふつうは韓国語1かたまり＝1組。日本語の1つの文が2つの韓国語のかたまりにまたがるときだけ、その韓国語をまとめて1組にする
- `ja` には、その韓国語にあたる日本語の文の番号を、**韓国語の流れに沿う順**で並べる。日本語の順番が入れ替わっている所は、韓国語の順に合わせて並べ直してよい（確かめるスクリプトが「入れ替え」と知らせるだけで、誤りではない）
- **日本語に無い韓国語**は、`ja` の中のあるべき位置に `{"ko": "省かれている韓国語"}` として入れる。文の一部が省かれているときは、その部分だけ（読点・句点までの区切りのよい所で）。かたまりが丸ごと無ければ、そのかたまりの全文を入れる。**字は原文からそのまま写す**（スクリプトが原文の中にあるかを確かめる）。あとでここを日本語に AI 訳して埋める
  - 細かい言い回しの違い・意訳・少しの言葉の足し引きは「省略」に数えない。**中身（出来事・人・数・発言・理由・場面）が日本語から消えているもの**だけを `{"ko"}` にする
  - 従属節でも、事実を足すもの（何をした・いつ・誰が・なぜ。例:「일본 선교활동 계획을 모두 준비한 뒤」）は拾う。韓国語を1つ残らず日本語の側に出すのが目標
  - `{"ko"}` の字は、`work/sections/NN.json` から機械で切り出してよい（写し間違いが起きない）。そのための使い捨てのスクリプトは、リポジトリの中ではなく scratchpad（`C:\Users\PC_User\AppData\Local\Temp\claude\E--auto-videos-creation\a85a5e0d-a243-4061-9624-972a79241584\scratchpad\`）に置く
- 日本語の中身が韓国語と食い違う所（数・場所・年・人数など。省略ではなく書き換わっている所）は、組の `note` に「食い違い: 」で始めて書く（例「食い違い: 飢える人を韓国語は数千万人、日本語は数億人」）
- 日本語にだけあって韓国語に無い文（訳者の補足など）は、いちばん近い組の `ja` に入れて、`note` に書く。韓国語の無い組（`"ko": []`）は、どの組にも入れられないときだけ
- `note` は日本語で短く。省略・入れ替え・迷った所を書く。何も無ければ書かなくてよい
- 53（6章7節）は韓国語が元のファイルに無いので、`{"ko": [], "ja": [全部の番号]}` の1組だけでよい
