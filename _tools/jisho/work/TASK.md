# 原理用語の日韓英辞書 — 訳語を決める作業

『原理講論』（韓国語の原典『원리강론』、日本語訳、英語訳 *Exposition of the Divine Principle* 1996年版）を段落ごとにそろえたデータから、用語の日・韓・英の対応表を作る。サイト「み旨の裏庭」の辞書（ポケ辞書のように、どの言語で引いても3つが並んで出る）の元になる。**読む人は本の言葉で引くので、訳語は必ずその本に実際に出ている形にする。自分で訳さない。**

## 道具
- `python -X utf8 find.py row 1-1-1:3` … その段落の韓・日・英の全文
- `python -X utf8 find.py ja 復帰摂理 5` / `find.py ko 복귀섭리 5` / `find.py en "providence of restoration" 5` … 字句が出る段落（他の2言語の頭も出る）
- `python -X utf8 find.py count en "indemnity condition"` … 何段落に出るか
- `python -X utf8 cooc.py "Abraham"` … 英語の固有名詞が出る段落に、どの日本語のカタカナ語・韓国語の語頭がそろって出るか
- `python -X utf8 validate.py outN.jsonl batchN.json` … 出力の検査。**最後に必ず通し、エラー 0 にする**

段落の番号は `節の鍵:段落`（例 `1-1-1:3`。0-0-0 は総序、1-1-x は前編第1章「創造原理」の第x節、2-x-x は後編）。

## 入力（batchN.json の1件）
`id`・`cat`（下の区分の仮決め）・`ko`（ハングル。機械で切り出したので語頭が欠けていることがある）・`hanja`（韓国語の本文で添えてある漢字）・`ja_guess`（漢字を新字体に直しただけのもの）・`ja_hit`（row = その段落の日本語に ja_guess がそのまま出た／all = 本のどこかには出る／none = 日本語訳では別の言い方）・`count`・`occ`（漢字が添えてある段落）・`en_candidates`（英語の候補を機械で数えたもの。**外れも多い**）・`ruby`（日本語訳のルビ）・`context`（最初の2か所の抜き出し）

## 出力（outN.jsonl、1件1行の JSON）
```
{"id": 35, "cat": "P", "ja": "授受作用", "yomi": "じゅじゅさよう", "ko": "수수작용", "hanja": "授受作用", "en": "give and take action", "en_alt": [], "ref": "1-1-2:3"}
{"id": 9, "cat": "L", "ja": "エジプト", "yomi": "", "ko": "애급", "hanja": "埃及", "en": "Egypt", "en_alt": [], "ref": "1-4-1:22"}
{"id": 113, "drop": true, "reason": "詳述＝ふつうの言葉で、原理の用語ではない"}
```
- **ja**: 日本語訳に実際に出る形。`ja_hit` が none のときは、日本語訳が別の語を使っている（例: 埃及→エジプト、方舟→箱舟）。その段落の日本語を読んで、対応する語を探す。送り仮名・「の」などを含めてよい（例「善悪の果」）。
- **yomi**: ja のよみ（ひらがな）。カタカナだけの語は空でよい。`ruby` があればそれに従う。統一原理での読み慣わしを使う: 蕩減=とうげん、摂理=せつり、四位基台=しいきだい、基台=きだい、授受作用=じゅじゅさよう、二性性相=にせいせいそう、性相=せいそう、形状=けいじょう、本性相=ほんせいそう、霊人体=れいじんたい、肉身=にくしん、生心=せいしん、肉心=にくしん、重生=じゅうせい、侍義=じぎ、天宙=てんちゅう、心情=しんじょう、本然=ほんぜん、長成=ちょうせい、蘇生=そせい、主管=しゅかん、讒訴=ざんそ、復帰=ふっき、万物=ばんぶつ、実体=じったい、献祭=けんさい、再臨=さいりん、初臨=しょりん、聖殿=せいでん、正分合作用=せいぶんごうさよう、個性真理体=こせいしんりたい、天使長=てんしちょう、嗣業=しぎょう。分からない読みは推測で埋めず、`flag` に書く。
- **ko**: 韓国語の本文の形（ハングル）。語頭の欠け・数字（`3대 축복`）を直す。分かち書きは本文どおり。
- **hanja**: 本文に添えてある漢字（旧字体のまま）。切り出しが崩れていれば直す。
- **en**: 英語訳での言い方。**ref の段落の英語にそのままの字句で出ていること**（大文字小文字は問わない）。普通名詞は小文字・単数・冠詞なし（`indemnity condition`、`archangel`）、固有名詞は本文どおり（`Egypt`、`Second Advent`）。英語訳が意訳していて対応が取れない段落なら、`occ` のほかの段落や `find.py ja …` で、きれいに対応する段落を探して ref にする。どうしても無いときだけ drop（reason に書く）。
- **en_alt**: 英語訳で同じ語に使われるほかの言い方（あれば。最大3つ。英語のどこかに出ること）。例: 再臨 → en "Second Advent"、en_alt ["Second Coming"]。
- **ref**: ja・ko・en の3つがそろって出る段落。最初に出る所か、その語を説明している所を選ぶ。
- **cat**: P=原理の用語（創造原理・四位基台・蕩減条件・時代の名前など）、F=信仰・聖書（再臨・十字架・幕屋・預言者など）、H=歴史・思想（宗教改革・封建社会・唯物論など）、L=地名・国・民族、N=人名。仮決めが明らかに違えば直す。
- **drop**: 調べてみて、原理講論を読む人・訳す人が引く語でない（ありふれた言葉）、同じ束の別の id と ja・ko が同じ（reason に「id 40 と同じ」）、または英語の対応がどこにも無い。
- **flag**: 迷ったこと・確かでないことを日本語で一言（任意）。

## 注意
- en_candidates をそのまま使わない。必ず段落の英語を読んで、その語に当たる字句を選ぶ（例: 霊人体の候補に "spirit world" が出るが、正しくは "spirit self"）。
- 1語に1行。入力のすべての id について出力する（drop も1行）。
- 最後に `validate.py outN.jsonl batchN.json` でエラー 0 を確かめ、件数（残した・drop）と flag の付いた id を報告する。
