# cafe_books — Daum カフェの掲示板から本を組む

八大教材・教本のうち、このサイトに無かった3冊と、天一国経典の2冊を、Daum カフェ「천일국 경전방」の掲示板にある日本語版から組んだ（2026-10-31）。

| 本 | 掲示板 | フォルダ | 組み方 |
|---|---|---|---|
| 天国を開く門 真の家庭 | VS04 | tengoku_mon/ | 節ごとの記事（2〜38）。章ごとに1ページ |
| 平和の主人 血統の主人 | VWMp | heiwa_syujin/ | 全文の記事 36（節ごとの記事 2〜34 と同じ訳の手直し版）。33の見出しごとに1ページ |
| 世界経典 Ⅱ | VyWS | sekai_kyouten2/ | 1記事＝1小節（514本）。部・章・節・小節は記事の頭の行と題から。章ごとに1ページ |
| 真の父母経 | V1yh | makotonofubokyou/ | 1記事＝1節（184本）。篇・章ごとに1ページ（45）。篇の前書きはその篇の最初のページの頭 |
| 平和経 | V1yi | heiwakyou/ | 1記事＝1講演（182本。第四篇14は①〜⑤の5本を1ページに）。講演ごとに1ページ（178） |

作り直すときはリポジトリの根から:

```
python -X utf8 _tools/cafe_books/crawl.py VS04 VWMp VyWS V1yh V1yi   # raw/ に記事を落とす（一度落としたものは取り直さない）
python -X utf8 _tools/cafe_books/parse.py VS04 VWMp VyWS V1yh V1yi   # raw/<掲示板>.jsonl
python -X utf8 _tools/cafe_books/build_books.py            # 全部（1冊だけなら tengoku / heiwa / sekai / fubo / heiwakyou）
```

**落とした記事（raw/<掲示板>/*.html）は、組み終えたらリポジトリの外（`E:\mimune-no-uraniwa\cafe-raw\`）へ移す。** `_tools/` の下に HTML があると、build_fulltext.py が検索の本文に `_tools` という本を作る（raw/*.jsonl は残してよい）。

そのあと、本を足したときの決まりの台本を回す（sitemap → seo_titles → extract_inline_css → build_fulltext → build_downloads → build_offline_manifest → build_gacha）。
ページの形は touitusisou/（統一思想要綱）を写している。
