# 原理原本の日本語訳 — 作業の手順

『原理原本』（文鮮明先生が 1951〜52年に書いた原稿。韓国語、漢字まじり）を、段落ごとに日本語に訳す。サイト「み旨の裏庭」で原文と並べる日韓対訳になる。読む人は原文と見比べるので、**訳は最大限、原文に近く**する（ユーザーの指定）。

作業フォルダ（以下すべてここ。Python は `python -X utf8`）:
（記事を落として作った pages2.jsonl・units2.json・wbN.json を置いたフォルダ。リポジトリには入れていない）

## 入力（wbN.json の1件）
- `id` 段落の番号、`pages` 原稿のページ
- `ko` 原文（Daum カフェの掲示板に写されたもの）。段落の途中で原稿のページが替わる所に `〔123〕` の印がある
- `ja_board` 掲示板にある日本語訳（김현주 さんの訳）。**誤訳・誤字が多い**（他性的→「惰性的」、同性體→「同姓体」、引力→「人力」、元祖→「援助」など）。答え合わせにだけ使い、言い回しを写さない
- `head_guess` 見出しらしい短い行（機械の推測）

## 出力（outN.jsonl、1件1行の JSON。入力のすべての id について）
```
{"id": 1, "ja": "一から全存在へ", "heading": true}
{"id": 2, "ja": "太初はすなわち一つであられる。この一つがすなわち太初の根本である。この根本がすなわち神様であられる。"}
{"id": 7, "ja": "この存在から第二存在にまで到達させる、決定的な基本点となることが分かる。それでは、この第二存在〔2〕の要求は何かといえば、……", "note": "原文「具成」は構成の意として訳した"}
```
- `ja` 訳文。`ko` にある `〔123〕` の印は、訳文の対応する位置に同じ形で入れる（数も順もそろえる）
- `heading` その段落が見出し（節の題）なら true。本文の文なら書かない。見出しは短く、文として終わっていない。「◎」「①」などの印は訳文にも残す
- `note` 任意。原文の誤字を直して訳した、意味が取れず推測した、など読む人に断りが要る所を日本語で一言
- `board` 任意。掲示板の訳が意味を取り違えている所を見つけたら一言（例「他性的→惰性的」）。サイトには出さず、訳の確かさの記録にする

## 訳し方（決まり）
1. **하나님 は「神様」**。敬語は残す（하나이시다 → 一つであられる、創造하셨다 → 創造された／なさった）
2. **文の数と順は原文どおり**。1文を1文に。言葉を足して説明しない。どうしても補うときは（　）に入れる
3. **原文の漢字語は、その字のまま**（天宙・路程・性品→性稟・本然・実格・存生・帰一・妙理・聖神・聖経 など）。旧字体は新字体に（體→体、對→対）。原稿の略字は普通の字に（厂史→歴史、囗家・囗→国家・国）
4. 原文がハングルで書いている語は、原理講論の日本語に合わせる（예수→イエス、해와→エバ、아담→アダム、사탄→サタン、탕감→蕩減、세례 요한→洗礼ヨハネ）。`glossary.tsv`（原理用語辞典の 韓国語→日本語）を引く
5. 原文が漢字の後に添えたハングルの読み・言い換え（`囗(국가)`、`吽音(불리우며)`、`勝(승리)`）は、訳では添えず意味を訳す。原文が漢字で添えた言い換え（`원인(基因)`）は「原因（基因）」と残す
6. 聖書の引用は原文の文をそのまま訳す（日本語の聖書の文に置き換えない）
7. 文体は「である」調（原文の「〜다」）。「〜ところである」「〜のである」を重ねすぎない
8. 原文の字が別の語の意味に取れる所は、その意味で訳し、`note` に「原文「持点」は支点の意として訳した」の形で書く。「書き誤り」「誤り」とは書かない（原文の字にも意味があるかもしれない。ユーザーの指定）。ただし言い換えた語も日本語としてなじみの薄い語なら、原文の字のまま（複雑多段・結判。ユーザーの指定）。意味の取れない所は推測で訳し、`note` に「推測」と書く
9. 見本: `pilot.json` は1巻1〜10ページを原稿のページごとに訳したもの（`pages.jsonl` の段落の順）。文体と語の選び方をこれに合わせる（ページの切れ目でつないだ段落は、つないだ形で訳し直す）

## 道具
- `python -X utf8 validate_wb.py outN.jsonl wbN.json` … 全部の id があるか、〔ページ〕の印がそろっているか、ハングルが残っていないか、長さが極端でないかを見る。**最後に必ず通し、エラー 0 にする**（「注意」は読んで、問題なければそのままでよい）

## 注意
- 1段落ずつ、原文を読んで訳す。掲示板の訳を下敷きにしない
- outN.jsonl は1件ずつ書き足していく（途中で止まっても残るように）
- ほかの束（ほかの番号の wb・out）には触れない
