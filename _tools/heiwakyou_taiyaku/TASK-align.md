# 韓日の対応付けと注（天一国経典『平和経』）

『平和経』の韓国語の原文と日本語版を、講演ごとに「どの韓国語のかたまりが、どの日本語の文にあたるか」で対応させ、読む人向けの注も同じときに書く。
できた対応表から、サイトで韓・日（のちに英）を横に並べる対訳を作る。**韓国語が正。** 目標は**韓国語も日本語も1つ残らず、正しい相手と組になること**（ユーザーの方針: 入れ替えや補助の訳を入れてでも、正確に分けて組にする）。
やり方は『平和を愛する世界人として』の対訳（`_tools/heiwa_sekaijin/`）と同じ。

## 材料（読むだけ。書き換えない）
- `work/sections/HHNN.txt` … 講演ごとの一覧（HHNN は篇2桁＋講演の番号2桁。0101 は第一篇1）
  - `K1:` が韓国語のかたまり（原文の段落）。`K3 [頭]:` は日付・場所・行事の行、`K5 [見出し]:` は小見出し
  - `J1 [p1]:` が日本語の文（`[p1]` はサイトの段落）。`[p1 頭]`・`[p4 見出し]` も同じ意味
- `work/sections/HHNN.json` … 同じものの JSON（`{"ko"}` の字を機械で切り出すときに使う）
- 日本語版は韓国語から訳したもので、おおむね忠実。ただし、小見出しを丸ごと落とした講演（0411・0515・0605・0611・0919 など）や、段落・文を省いた所、2〜3段落を1段落にまとめた所、日付が1日ずれている所（0905・1006・1013）がある

## 書くもの: `work/align/HHNN.json`

```json
{"key": "0101", "groups": [
  {"ko": [1], "ja": [1]},
  {"ko": [2], "ja": [2]},
  {"ko": [5], "ja": [5]},
  {"ko": [6], "ja": [6, 7, 8]},
  {"ko": [7, 8], "ja": [9, 10, 11], "note": "J10 が K7 の終わりと K8 の頭にまたがる"},
  {"ko": [9], "ja": [12, {"ko": "그때 형사들은 나를 거꾸로 매달고 물을 부었습니다."}, 13], "note": "日本語は1文省いている"},
  {"ko": [10], "ja": [{"ko": "1. 하나님의 이상가정"}], "note": "日本語版にはこの小見出しが無い"},
  {"ko": [11], "ja": [14, 15], "diff": ["原文では一九八一年十月二十二日（日本語版は「十月二十一日」）"]},
  {"ko": [12], "ja": [16, 17], "ja_only": [17], "ja_only_ko": "이 말씀은 8대 교재·교본 중 하나입니다."}
]}
```

### 組の決まり
- `groups` は韓国語の順に並べる。どの組も `ko`（韓国語の番号、連続した昇順）と `ja`（日本語）を持つ
- **組はできるだけ小さく。** ふつうは韓国語1かたまり＝1組。日本語の1つの文が2つの韓国語のかたまりにまたがるときだけ、その韓国語をまとめて1組にする
- **`[頭]` と `[見出し]` の韓国語は、1つで1組にする**（ほかの韓国語と同じ組に入れない。画面ではこの組が見出しの行になる）。日本語の見出しは、韓国語の見出しの組に入れる
- `ja` には、その韓国語にあたる日本語の文の番号を、**韓国語の流れに沿う順**で並べる。日本語の順番が入れ替わっている所は、韓国語の順に合わせて並べ直してよい（確かめるスクリプトが「入れ替え」と知らせるだけで、誤りではない）
- **日本語に無い韓国語**は、`ja` の中のあるべき位置に `{"ko": "省かれている韓国語"}` として入れる。文の一部が省かれているときは、その部分だけ（読点・句点までの区切りのよい所で）。かたまりが丸ごと無ければ、そのかたまりの全文を入れる。日本語版に無い小見出しも同じ（`{"ko": [10], "ja": [{"ko": "（K10 の全文）"}]}`）。あとでここを日本語に AI 訳して埋める
  - **字は原文からそのまま写す**（スクリプトが原文の中にあるかを確かめる）。`work/sections/HHNN.json` から機械で切り出すとよい。使い捨てのスクリプトはリポジトリの中ではなく scratchpad（`C:\Users\PC_User\AppData\Local\Temp\claude\E--auto-videos-creation\57799137-dc40-4ef5-8c7c-7a762b6632f5\scratchpad\`）に置く。ほかの担当も同時に同じフォルダを使うので、**ファイル名に講演の番号を入れる**（`align_0305.py` など）
  - 細かい言い回しの違い・意訳・少しの言葉の足し引きは「省略」に数えない。**中身（出来事・人・数・発言・理由・場面・例え・列挙の項目）が日本語から消えているもの**だけを `{"ko"}` にする
  - 従属節でも、事実や中身を足すもの（何をした・いつ・誰が・なぜ）は拾う。韓国語を1つ残らず日本語の側に出すのが目標
- 日本語にだけあって韓国語に無い文は、いちばん近い組の `ja` に入れる（下の `ja_only` も書く）。韓国語の無い組（`"ko": []`）は、どの組にも入れられないときだけ
- `note` は作業者向けのメモ（画面に出ない）。日本語で短く。省略・入れ替え・迷った所を書く。何も無ければ書かなくてよい

### 読む人向けの注（画面に出る）

**`diff`（日本語の欄の下に「※」で出る）** … 日本語版が**中身を書き換えている所**を、1つ1文で書く。
- 対象: 数・年・日付・期間・場所・人数・人名などが違う所／意味が逆・別になっている所／文の途中の語句が落ちて意味が変わる所／発言の中身が違う所
- 形: **「原文では〜（日本語版は「〜」）」**。原文の中身は自分で日本語に訳して書く。日本語版の言い方は「」で引く
  - 例「原文では二十二日（日本語版は「二十一日」）」「原文では「全世界の青年」（日本語版は「青年」とだけ）」
- 書かないもの: 言い回し・意訳の違い／訳者が足した括弧の説明／日本語の見出しにだけ番号（「1.」）が付いているといった形の違い／日本語に無い文や語句で、`{"ko"}` の AI 訳で補うもの（AI 訳の行に出るので、注で繰り返さない）
- 番号（J12・K3・組）や「韓国語の」「J20 は」のような作業の言葉は入れない。読む人には通じない

**`ja_only` と `ja_only_ko`（日本語版にしか無い文）** … 日本語版にあって**原文の韓国語に無い文**を、その組の `ja` にある文の番号で `ja_only` に並べる。
- 文の一部に括弧の説明が足されているだけなら入れない。**文の中身がまるごと原文に無い**ものだけ
- `ja_only_ko` には、その文（複数なら全部）を韓国語に訳して書く。原文と同じ文体（「-습니다」体）で、用語は原文の書き方に合わせる（神様＝하나님、真の父母＝참부모）

### 迷いやすい所の決め方（試しの回で出た問い）
- **短い語句の省略は `{"ko"}` か `diff` か**: 文、または読点で区切れる節がまるごと落ちていれば `{"ko"}`。**前の文のくり返しや短い問いかけ（「그것이 무엇입니까?」）でも、文がまるごと無ければ `{"ko"}` にする**（韓国語の欄の文が、日本語の欄で1つも欠けないようにするため）。それより短い語句（「또는 통일세계」「공격을 하든」など、読点で区切れない所）が落ちて中身が変わるなら `diff`。中身が変わらなければ何も書かない
- **韓国語の原文のほうが誤りらしい所**（打ち消しが抜けている、字が違うなど、前後から見て日本語版のほうが筋が通る所）: `diff` は書かず、`note` に「原文の疑い: 〜」と書く。韓国語は正だが、原文の書き誤りを「日本語版が書き換えた」と読む人に見せないため（あとでまとめて確かめる）
- **訳語の決まりで項目がつぶれる所**（씨족も종족も「氏族」になる、など）: 省略にも `diff` にもせず、`note` だけ
- **日本語版の字の誤り**（「家庭党」を「家庭堂」、「国連」を「国運」など）: 意味が変わって見えても `diff` にせず、`note` に「日本語の字: 〜は〜の誤りか」（あとでサイトの日本語を直す）
- **日本語の1文が「。」で2つに切れている所**: 2つとも同じ組に入れる。`note` は要らない
- **同じものを別の形で言っているだけの所は `diff` にしない**（`note` だけ）: 「天一国5年」→「二〇〇五年」のような年の数え方の書き換え、「二百を超える」→「約二百」のようなおおよその数の言い方
- **意訳と中身の違いの境目**: `diff` にするのは、数・年・日付・人・場所・主語と目的語・打ち消し（逆の意味）・列挙の項目が変わる所と、比喩や理由の中身が別のものになっている所（例「力が同じくらいなので」→「心と体があるので」、「雲に乗って来てはならない」→「雲に乗って来ると文字どおり信じてはいけない」）。言い方の強さ・調子の違い（「成し遂げてみせる」→「成し遂げなければならない」）、引用の言い回しを縮めただけで言っていることが同じ所、文の組み替えは `diff` にしない

## 気をつけること
- 渡された講演だけを書く。ほかのファイル（材料・スクリプト・ほかの講演）は触らない
- 韓国語・日本語の本文を直さない。対応を付けるだけ。日本語版の字の誤り（読み取りの誤りなど）に気づいたら、その組の `note` に「日本語の字: 〜は〜の誤りか」と書く
- 推測で埋めない。韓国語を読んで、日本語のどの文が同じことを言っているかを確かめて組にする
- 長い講演も、最初から最後まで全部読んで組にする。途中から機械的に割り振らない
